# Маршрут практики

Маршрут: standard. Роли: оркестратор, разработчик, независимый тестировщик.

Контекст: учебный Python-каркас, готового ML-кода нет. README описывает каталоги; requirements.txt содержит pandas, numpy, scikit-learn и инструменты анализа. Файл sample_students.csv представлен только DVC-указателем. Правила: Personal Codex Baseline. Ветка: codex/practice-ml-pipeline.

Критерии приёмки из скриншота:
1. Реальный датасет с числовыми и категориальными признаками, воспроизводимое train/test-разбиение.
2. Pipeline: медианная импутация и масштабирование числовых признаков; most_frequent и OneHotEncoder для категорий; LogisticRegression.
3. Кастомный sklearn-трансформер считает пропуски до импутации и добавляет числовой признак.
4. GridSearchCV подбирает минимум два гиперпараметра только на train; препроцессинг обучается внутри CV без утечки.
5. Выведены best_params_ и метрики отложенного test; сохранены реальные результаты и объяснение.
6. Запуск из корня репозитория, данные доступны локально; независимая проверка кода и фактического выполнения.

Реализация: Titanic из seaborn-data, небольшой явный набор входных признаков без alive и других дублирующих цель колонок. Локальный CSV, источник и SHA-256 фиксируются в документации. Подбор classifier__C и classifier__class_weight сохраняет требуемую медианную импутацию во всех кандидатах.
