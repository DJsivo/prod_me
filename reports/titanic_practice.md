# Практическая работа: обработка смешанных данных в Pipeline

## Данные и цель

Использован Titanic из [seaborn-data](https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv).
Локальная копия `data/external/titanic.csv` содержит 891 пассажира.
Цель — предсказать выживание (`survived=1`). В выборке 342 выживших и
549 погибших. SHA-256 исходного CSV:
`81787d320d7f7b03df935e91de8bd19e11d45c5bbcab86ef4d4a76dc91b7d4f2`.

Числовые признаки: возраст, число братьев/сестёр и супругов, число
родителей/детей, стоимость билета (`age`, `sibsp`, `parch`, `fare`).
Категориальные: класс билета, пол, порт посадки и палуба
(`pclass`, `sex`, `embarked`, `deck`). В возрасте 177 пропусков,
в порте посадки — 2, в палубе — 688. Остальные выбранные признаки заполнены.
Колонка `alive` не используется: она дублирует целевую переменную.

## Обработка и обучение

Стратифицированное разбиение с `random_state=42` выделяет 712 строк для
обучения и 179 для теста. Сначала кастомный `MissingCountAdder` считает
пропуски в восьми исходных признаках каждой строки и добавляет `missing_count`.
Он создаёт копию таблицы, поэтому не изменяет исходные данные.

Затем `ColumnTransformer` применяет две ветви обработки. Числовые признаки,
включая `missing_count`, проходят заполнение медианой и `StandardScaler`.
Категориальные признаки проходят заполнение самой частой категорией и
`OneHotEncoder(handle_unknown="ignore")`. Финальный шаг — `LogisticRegression`.

`GridSearchCV` сравнивает шесть сочетаний двух гиперпараметров:
`classifier__C` принимает 0.1, 1.0 и 10.0; `classifier__class_weight` —
`None` и `"balanced"`. Каждый кандидат проверяется на пяти стратифицированных
фолдах с перемешиванием и `random_state=42`. Критерий выбора — ROC AUC.
Весь Pipeline передан в поиск: медианы, категории и параметры масштабирования
обучаются заново внутри каждого фолда. Test не участвует в подборе.

## Фактические результаты

Запуск: `python -m src.models.titanic_pipeline`. Окружение:
Python 3.11.6, NumPy 2.4.6, pandas 3.0.6, scikit-learn 1.9.1.
Полный машинно-читаемый результат сохранён в `reports/titanic_metrics.json`.

`best_params_ = {'classifier__C': 0.1, 'classifier__class_weight': None}`.
Средний ROC AUC лучшего кандидата в CV: **0.860268**.

| Метрика на test | Значение |
|---|---:|
| Accuracy | 0.815642 |
| Precision | 0.821429 |
| Recall | 0.666667 |
| F1 | 0.736000 |
| ROC AUC | 0.842161 |

Для метрик по меткам положительный класс — выживший пассажир,
порог вероятности — 0.5. ROC AUC рассчитывается по вероятностям.

| Истинный класс / прогноз | Погиб (0) | Выжил (1) |
|---|---:|---:|
| Погиб (0) | 100 | 10 |
| Выжил (1) | 23 | 46 |

Модель верно классифицировала 146 из 179 пассажиров тестовой выборки.
Она обнаружила 46 из 69 выживших, пропустив 23; среди 56 прогнозов
выживания 10 ошибочны. Это объясняет более высокую precision по сравнению
с recall. Test ROC AUC ниже среднего CV ROC AUC примерно на 0.018.
Один фиксированный holdout не позволяет оценить неопределённость качества;
результат относится к этому разбиению исторического набора данных.

## Воспроизводимость

Локальный CSV позволяет повторить обучение без загрузки данных из сети.
Фиксированы разбиение и фолды, а JSON сохраняет версии библиотек, хеш данных,
параметры каждого кандидата и его среднее и стандартное отклонение ROC AUC.
При другом окружении возможны небольшие численные различия.
Инструкции установки и запуска приведены в `README.md`.
